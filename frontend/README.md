# SpecsVision Frontend

React 19 & TypeScript frontend application for SpecsVision featuring Virtual Try-On, 3D model inspection, and admin dashboard.

Refer to the main [Root README](../README.md) for full project setup and architecture details.

## Available Scripts

* `npm start` — Run client dev server on `http://localhost:3000`
* `npm run build` — Build static bundle for production
* `npm test` — Run unit tests
